# 🎛️ Monochrome UI Core — void.css (EN)

Everything a web developer needs for ultra-clean black & white layouts collected in one single file. Pure aesthetics with insane attention to detail.

### 🔥 Features:
* **Animations:** Sweep, draw, shine buttons, click ripples, and morphing loaders.
* **Inputs v2:** Floating labels, custom switches, beam outlines, and OTP fields.
* **Loaders:** Skeleton shimmers, dot bounces, and conic-gradient progress circles.
* **Components:** macOS docks, command palettes (⌘K), and terminal themes.
* **Spoilers:** Discord/Telegram style blur-blocks and solid click-reveals.
* **Extras:** Custom scrollbars, responsive tables, timelines, and chip tags.

*Educational purposes only. Use at your own risk. frfr 🤝*
